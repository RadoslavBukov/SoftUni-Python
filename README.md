## 🏆 Key Projects

### 1. Petstagram
A full-featured Instagram-like social network for pet owners
- **Technologies**: Django, PostgreSQL, Django Forms, Signals
- **Features**:
  - User authentication and profiles
  - Pet profiles with photos
  - Photo feed and interactions
  - Comments and likes
  - Follow/unfollow functionality
  
**Versions**:
- v1: Basic functionality (Python Web Basics)
- v2: Advanced features (Python Web Framework)
- v3: Professional deployment (Python Web Framework)

### 2. Todo App
Full-stack application with React and Django REST
- **Frontend**: React with hooks
- **Backend**: Django REST Framework
- **Features**:
  - User authentication
  - Task management (CRUD)
  - Task categories
  - REST API endpoints
